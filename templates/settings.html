Connect Claude Code

Add this to your .mcp.json in the project root (or ~/.claude/claude_desktop_config.json for global access). Replace <HOST> with the PulseBoard server address. 

{
  "mcpServers": {
    "pulseboard": {
      "type": "sse",
      "url": "http://<HOST>:8010/mcp/sse",
      "headers": {
        "Authorization": "Bearer {% if api_token %}{{ api_token }}{% else %}<your-token>{% endif %}"
      }
    }
  }
}
